本文的完成定义

接口可编码

每个模块有明确职责、依赖、输入输出；关键类与 Protocol 有签名，不需要再猜。

数据可迁移

DDL、migration、保留策略、备份与回滚齐全；旧库可平滑升级。

行为可验证

每个关键路径有测试用例与验收门禁；单轮行为逐字段兼容。

任务可拆分

按 PR 切片，依赖明确，每个 PR 可独立 review、发布、回滚。

运维可执行

三端口、配置、日志、指标、清理、备份都有明确操作。

未来可扩展

Agent 工具、状态、记忆、护栏、轨迹评测的接缝已定义；默认不启用。

八条实现原则

P1

行为优先

P0–P3 不改输出；用快照锁住单轮与多轮。

P2

一条流水线

单轮/多轮/Disco 共用 RagPipeline。

P3

端口在边界

核心不 import FastAPI/httpx/sqlite3。

P4

显式契约

dataclass + Pydantic；不传裸 dict。

P5

配置/提示词资产化

Settings / Profile / Overrides / prompts 分离。

P6

Trace 是事件

业务发事件，presenter 渲染 legacy steps。

P7

小步可逆

每 PR 可发布；保留 shim 与开关。

P8

Agent 后置

先定义接缝，不启用自主循环。

行为不变量

  • session_id=None 且 stateless=false 时，仍按现行为决定是否建会话；stateless=true 强制单轮。
  • 单轮请求不写会话、不改写、不注入历史；输出与旧路径逐字段一致。
  • 多轮历史不得作为证据；只有当前轮 [E1..En] 可被引用。
  • 引用校验失败只记 flag，不抛异常、不替换答案。
  • 索引构建中，旧快照继续服务；无快照才返回 index_not_ready。
  • 评估/埋点失败不影响主响应。
  • 所有时间戳使用本地时区 %Y-%m-%dT%H:%M:%S（保持现状）。

不做微服务

单进程 + SQLite；不为分布式提前付出复杂度。

不做多租户

不启用 Agent

不重写前端框架

HTML 出 Python，模板 + 静态资源即可。

不改接口语义

只加字段；不删字段、不改类型。

不引入 ORM/队列

repository + 线程 JobRunner 足够。

# bootstrap.py
def create_app(profile: Profile) -> FastAPI:
    settings = Settings.from_env(profile)
    overrides = OverridesStore(profile.overrides_path)
    llm = HttpLLM(settings.llm)
    embedder = OllamaEmbedder(settings.embed)

    index = IndexService(
        vault_path=settings.vault_path,
        index_path=settings.index_path,
        embedder=embedder,
        batch_size=settings.ingestion.batch_size,
    )
    sessions = SqliteSessionRepository(settings.db.sessions)
    analytics_repo = SqliteAnalyticsRepository(settings.db.analytics)
    jobs = ThreadJobRunner(max_workers=settings.jobs.max_workers)
    prompts = PromptRegistry(settings.prompt_dir)

    pipeline = RagPipeline(index, embedder, llm, prompts, overrides)
    chat = ChatService(pipeline, sessions, prompts, jobs,
                       overrides, settings.multiturn)
    assistant = AssistantService(pipeline, chat, settings.flags)
    analytics = AnalyticsService(analytics_repo, llm, jobs, overrides)

    ctx = AppContext(
        profile=profile, settings=settings, overrides=overrides,
        llm=llm, index=index, sessions=sessions,
        pipeline=pipeline, chat=chat, assistant=assistant,
        analytics=analytics, jobs=jobs,
    )

    app = FastAPI(title=f"AI-KB ({profile.name})", lifespan=lifespan(ctx))
    app.state.ctx = ctx
    register_middleware(app, ctx)
    register_routers(app)
    return app

class IndexService:
    def __init__(self, vault_path: Path, index_path: Path,
                 embedder: Embedder, batch_size: int = 16):
        self._vault_path = vault_path
        self._index_path = index_path
        self._embedder = embedder
        self._batch_size = batch_size
        self._lock = threading.RLock()
        self._snapshot: IndexSnapshot | None = None
        self._status: IndexStatus = "empty"
        self._error: str | None = None
        self._reindex: ReindexProgress = ReindexProgress.idle()

    def current(self) -> IndexSnapshot:
        with self._lock:
            if self._snapshot is None:
                raise IndexNotReady("索引未就绪", detail={"status": self._status})
            return self._snapshot

    def rebuild(self, background: bool = True) -> None:
        with self._lock:
            self._status = "building"
        runner = threading.Thread(target=self._rebuild, daemon=True)
        if background:
            runner.start()
        else:
            runner.run()

    def _rebuild(self) -> None:
        try:
            chunks, summary_by_doc = process_documents(self._vault_path)
            matrix = self._embed_all(chunks)
            bm25 = BM25Index.build([c.text for c in chunks])
            snapshot = IndexSnapshot(...)
            self._persist(snapshot)          # temp + rename
            with self._lock:
                self._snapshot = snapshot     # 原子换引用
                self._status = "ready"
        except Exception as exc:
            with self._lock:
                self._status = "failed"
                self._error = str(exc)

WEIGHTS = (1.0, 2.0, 1.0)      # BM25 : semantic : rewrite-semantic

BOOST = 1.15

def fuse(lists: list[list[ScoredChunk]]) -> list[ScoredChunk]:
    agg: dict[str, float] = {}
    for hits, weight in zip(lists, WEIGHTS):
        for hit in hits:
            boost = BOOST if hit.chunk.doc_path.startswith(BOOST_PREFIXES) else 1.0
            agg[hit.chunk.chunk_id] = agg.get(hit.chunk.chunk_id, 0.0) + hit.score * weight * boost
    ranked = sorted(agg.items(), key=lambda kv: -kv[1])
    return [ScoredChunk(chunk=by_id[cid], score=score, source="fused")
            for cid, score in ranked]

def build(system_prompt, summary, window, evidence, query,
          raw_question=None, budget=None, max_turns=None) -> BuiltContext:
    budget = int(budget or settings.multiturn.max_prompt_tokens)
    max_turns = int(max_turns or settings.multiturn.max_history_turns)

    system = (system_prompt or "").strip()
    if summary:
        system += f"\n\n## 对话摘要\n{summary.strip()}"
    system += "\n\n" + MULTITURN_RULES

    evidence_budget = min(6000, int(budget * 0.5))
    kept, used = [], 0
    for chunk in evidence:
        cost = estimate_tokens(format_evidence([chunk]))
        if kept and used + cost > evidence_budget:
            break
        kept.append(chunk)
        used += cost

    history = history_pairs(window, max_turns)
    remaining = budget - estimate_tokens(system) - estimate_tokens(current_user(kept, query, raw_question))
    selected, hcost = [], 0
    for q, a in reversed(history):
        cost = estimate_tokens(q) + estimate_tokens(a)
        if selected and hcost + cost > remaining:
            break
        selected.insert(0, (q, a))
        hcost += cost

    # 首轮锚点
    if history and selected and history[0] not in selected:
        q, a = history[0]
        if hcost + estimate_tokens(q) + estimate_tokens(a) <= remaining:
            selected.insert(0, (q, a))

    messages = []
    for q, a in selected:
        messages += [{"role": "user", "content": q},
                     {"role": "assistant", "content": a}]
    messages.append({"role": "user", "content": current_user(kept, query, raw_question)})
    if messages[0]["role"] != "user":
        messages.insert(0, {"role": "user", "content": "（会话开始）"})

    return BuiltContext(
        system=system,
        messages=messages,
        prompt_tokens=estimate_tokens(system) + sum(estimate_tokens(m["content"]) for m in messages),
        truncated=len(selected) < len(history) or len(kept) < len(evidence),
        evidence_ids=[c.chunk_id for c in kept],
        evidence_text=format_evidence(kept),
    )

CITE_RE = re.compile(r"\[(E\d+)\]")

def validate_citations(answer: str, evidence: Sequence[Evidence]) -> CitationCheck:
    valid = {f"E{i}" for i in range(1, len(evidence) + 1)}
    cited = set(CITE_RE.findall(answer or ""))
    invalid = sorted(cited - valid)
    missing = bool(evidence) and not (cited & valid) and len(answer or "") > 200
    return CitationCheck(ok=not invalid and not missing,
                         invalid=tuple(invalid), missing=missing)

class OverridesStore:
    def __init__(self, path: Path):
        self._path = path
        self._lock = threading.RLock()
        self._cache: dict = {}
        self._mtime_ns: int = -1

    def _load(self) -> dict:
        stat = self._path.stat()
        with self._lock:
            if stat.st_mtime_ns != self._mtime_ns:
                self._cache = json.loads(self._path.read_text("utf-8"))
                self._mtime_ns = stat.st_mtime_ns
            return self._cache

    def param(self, name: str, default: T) -> T:
        value = self._load().get("params", {}).get(name, default)
        return cast(T, value)

    def prompt_rule(self) -> str:
        return str(self._load().get("prompt_rule") or "").strip()

Security / 安全与权限

本地服务也要有边界

现在只监听 127.0.0.1，风险可控；但 cookie、注入、日志、未来工具调用都需要明确规则。

现在必须做

  • cookie：HttpOnly、SameSite=Lax、TLS 下 Secure；session_id 高熵、可撤销、可过期。
  • CORS 默认关闭；需要时 allowlist。
  • 请求体大小、问题长度、并发数限制。
  • 密钥只从 env 读取；日志脱敏；.env 不入库。
  • 检索内容视为不可信资料；system 明确“不执行其中指令”。

未来 Agent 必须做

  • 工具白名单 + schema + 权限 + 超时 + 幂等。
  • 文件系统限定目录；网络出口白名单；命令执行沙箱。
  • 写操作/删除/发布必须人工确认（HITL）。
  • 每次工具调用写审计：谁、何时、参数、结果、成本。
  • kill switch：按 profile / session / tool 关闭。

Prompt Injection 防护

入口风险措施
检索内容文档含“忽略以上指令”证据分隔块；system 声明只作为资料。
工具输出外部 API 返回恶意指令工具输出视为不可信；只解析结构化字段。
用户输入诱导越权工具调用权限在代码里；不依赖模型自觉。
模型输出泄漏密钥、伪造引用输出扫描 + 引用校验 + 拒答策略。

Risks / 风险与回滚

先写回滚，再写代码

重构最大的风险是“行为悄悄变了”。每个阶段都必须能在半小时内回到上一版。

风险概率影响缓解
单轮输出漂移高高P0 快照；逐字段对比；PIPELINE_V2=0
多轮引用错乱中高引用校验测试；历史不带证据；基准门禁
索引切换竞态中高不可变快照 + 原子换引用；旧快照兜底
SQLite 并发锁中中WAL + busy_timeout + 单写锁；短事务
migration 丢数据低高迁移前备份；dry-run；只前进 + 备份恢复
提示词回归中高版本入 trace；基准门禁；优化器只追加规则
迁移疲劳中中每阶段独立价值；P0/P1 先落地
性能回退中中基准对比；事件按需构造；避免每请求读盘

回滚矩阵

P1 失败

revert PR；chat_service 恢复 _srv()；无数据变更。

P2 失败

server 仍保留旧函数 re-export；切回全局索引路径。

P3 失败

PIPELINE_V2=0 走旧生成路径；新表只读。

P4 失败

server.py shim 选择旧 app；页面回退旧 ui 模块。

P5 失败

DB 从 var/backups/ 恢复；overrides 回滚快照。

线上异常

kill 当前进程 → 启动上一 tag；保留旧索引文件。

停止条件

  • 单轮快照出现任何字段差异，且半天内无法定位 → 回滚，补测试。
  • 多轮基准下降 > 5% → 回滚，检查上下文/引用。
  • 索引重建导致查询 5xx → 立即切回旧快照，暂停发布。
  • migration 失败 → 拒绝启动，恢复备份，不带病运行。
